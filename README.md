# 🎮 Сортер — Анти ИИ Qwen Академия

> Билингвальная детская игра-сортер. Полностью офлайн, без внешних зависимостей.
> Поддержка мыши, тач-устройств, клавиатуры и скринридеров (ARIA).

### ✨ Особенности
- 🌍 **Два языка**: русский и английский, переключение одной кнопкой
- 📱 **Адаптивный дизайн**: работает на телефонах, планшетах и ПК
- 👆 **Два способа игры**: перетаскивание (drag & drop) или нажатие на фигуру
- 🔊 **Звуковые эффекты** через Web Audio API (без аудио-файлов!)
- ♿ **Доступность**: полная поддержка клавиатуры и ARIA-меток
- 💾 **100% офлайн**: один HTML-файл — никаких CDN, никаких трекеров
- 🎨 **Glassmorphism-дизайн** с анимациями и конфетти при победе
- 💙 **Бесплатно навсегда** — открытый код для изучения и модификации
